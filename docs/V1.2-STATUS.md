# v1.2: status and next steps

Working notes for continuing the v1.2 work on branch `claude/inspiring-einstein-er2d37`.
1.2.0-beta.1 and 1.2.0-beta.2 are published as pre-releases (CHANGELOG.md says what each has);
a further release or a PR waits for the owner's go-ahead.

## Done (on the branch)

- Sound end to end (Mac capture, sealed UDP/TCP audio, WASAPI playback, jitter buffer).
- Typed address (IPv4/IPv6/name, `--direct`, Mac `--port`, dual-stack listener).
- Scoped `open_file`, drag and drop to open, adoption of apps opened on the Mac.
- Motion system, Liquid Glass (MobileLab, MIT), loading window, glass menu, MacBridge Search,
  reconnect banner, connection phases, keyboard modes, Settings entries.
- Desktop Fusion: the Mac's real Dock streamed, wallpaper set to the PC's and always restored.
- `macbridge.sh` launcher + `macbridge --check-permissions`; release tarball ships it.
- Guides, architecture, CHANGELOG.md, docs/QA-CHECKLIST.md, version 1.2.0-beta.2.
- From the first real CI screenshots: loading window now closes (it was re-armed on every
  frame), glass menu sized to its rows, Dock region kept even-sized (no green line).
- CI flake hardening: Open panel "closed" needs 3 checks in a row; fullscreen retries the AX
  window for 2 s; the Dock e2e check needs one decoded picture, not three frames.
- Diagnostics: per-step connection timings and app window/first-picture latency in the log.

## In flight (pushed, CI not yet seen)

- Record/replay of the real Mac Dock: the recorder's `dock` pseudo-app, the replay agent offers
  `fusion` and plays it on `dock_stream`, `RM_FUSION=1` forces Fusion on in a showcase, and the
  gallery step `14-fusion-dock` screenshots the Dock over the Windows desktop
  (`.github/workflows/mac-to-windows.yml` sets `RM_UI_GALLERY=1 RM_FUSION=1`).
